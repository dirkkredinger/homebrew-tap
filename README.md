# dirkkredinger/tap

Homebrew tap for my macOS apps.

```bash
brew tap dirkkredinger/tap
brew trust dirkkredinger/tap      # Homebrew 7+ asks you to trust third-party taps
brew install --cask soundladder
```

| Cask | Description |
|---|---|
| [soundladder](https://github.com/dirkkredinger/SoundLadder) | Menu bar app that picks your audio output from a ranked list |
